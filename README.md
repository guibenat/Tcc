## 📝 Sobre o Projeto
O **Lires** é uma plataforma educacional desenvolvida como Trabalho de Conclusão de Curso (TCC) na ETEC MCM. O objetivo principal é facilitar o aprendizado da **Libras (Língua Brasileira de Sinais)** através de uma interface intuitiva e acessível.

O projeto nasceu da vontade de usar a tecnologia como ferramenta de inclusão social, permitindo que usuários iniciantes possam praticar e conhecer o alfabeto e sinais básicos de forma interativa.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando a stack **JavaScript**:

- **Front-end:** [React.js](https://reactjs.org/) com Tailwind CSS para estilização.
- **Back-end:** [Node.js](https://nodejs.org/) com o framework Express.
- **Banco de Dados:** [MySQL](https://www.mysql.com/) para persistência de usuários e progresso.
- **Ferramentas:** Axios para consumo de API e Context API para gerenciamento de estado.
